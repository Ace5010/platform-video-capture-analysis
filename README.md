# 内容情报台

本机运行的多平台内容监控工作台。目前启用抖音采集，并为小红书、哔哩哔哩和 YouTube 预留接入口。数据仅保存在当前电脑，不保存完整视频，也不采集评论正文。

## 当前版本包含

- 对标账号主页链接、名称与真实头像管理（数量不设产品上限）
- 通过当前 Chrome 登录状态访问公开账号主页
- 首次添加账号时一次性抓取近 30 条非置顶视频
- 每 6 小时及手动检查时只读取最新 3 条非置顶视频
- “最新视频”和“总数据分析”按所选账号独立展示，不提供跨账号汇总视图
- 视频按账号与视频 ID 去重，新视频自动并入总数据分析
- 点赞、评论、收藏、分享四项独立汇总，以及按视频节点串联的四条趋势图
- 封面、视频文案、原视频链接、发布时间与时长
- 点赞、评论、收藏、分享数据快照
- 每次采集的数据快照
- 视频列表末尾的一键本地口播稿提取（不保存完整视频）

## 本地启动

```powershell
npm install
npm run setup:asr
npm run dev
```

`npm run dev` 会同时启动 Vinext 网站与本机 ASR 服务。打开终端显示的本地地址（默认 `http://localhost:3000`；若 3000 被占用会顺延到 3001）。

首次使用或扩展版本变化时，在 Chrome 的 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，加载本项目的 `chrome-extension` 文件夹；代码更新后点击扩展卡片的“刷新”，再刷新工作台页面。采集需要 Chrome 保持运行并维持抖音登录状态，但工作台网页可以关闭。

## 六小时后台检查

- Chrome 扩展用 `chrome.alarms` 注册真实的 6 小时周期，不依赖工作台网页中的计时器。
- 工作台关闭后，扩展仍会按时读取所有已完成首次建档的账号；结果先保存在扩展的本机存储中，下次打开工作台时自动回填。
- 账号新增、建档完成或移除时，后台监控名单会同步更新，避免继续采集已移除账号。
- 首页会直接显示后台调度是否注册、后台账号数、上次自动运行结果和下次计划时间。这些状态来自扩展，而不是页面自行推算。
- Chrome 完全退出或电脑睡眠/休眠时，扩展无法唤醒电脑；恢复 Chrome 后，错过的周期会执行一次补跑，再从恢复时间重新计算 6 小时。

首次点击“一键提取口播稿”会下载 faster-whisper 的 `small` 模型，模型和临时音频只保存在本机；临时音频识别完成后立即删除。

采集器会等待账号页真实出现 `/video/` 节点，跳过置顶作品，并从账号主页公开响应中读取完整字段。页面返回空列表或字段不完整会显示为失败，不会写入半成品或伪造数据。抖音页面结构变化后，可能需要更新采集适配器。
