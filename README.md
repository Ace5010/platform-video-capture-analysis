# 抖音对标监控

本机运行的抖音对标账号监控工作台。数据仅保存在当前电脑，不保存完整视频，也不采集评论正文。

## 当前版本包含

- 对标账号主页链接管理（数量不设产品上限）
- 通过当前 Chrome 登录状态访问公开账号主页
- 每 6 小时排队检查，以及手动立即检查
- 封面、视频文案、原视频链接、发布时间与时长
- 播放、点赞、评论、收藏、分享五项数据快照
- 每次采集的数据快照
- 视频列表末尾的一键本地口播稿提取（不保存完整视频）

## 本地启动

```powershell
npm install
npm run setup:asr
npm run dev
```

`npm run dev` 会同时启动 Vinext 网站与本机 ASR 服务。打开终端显示的本地地址（通常是 `http://localhost:3001`）。

首次使用或扩展版本变化时，在 Chrome 的 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，加载本项目的 `chrome-extension` 文件夹；代码更新后点击扩展卡片的“刷新”，再刷新工作台页面。采集需要在已登录抖音的 Chrome 中打开工作台。

首次点击“一键提取口播稿”会下载 faster-whisper 的 `small` 模型，模型和临时音频只保存在本机；临时音频识别完成后立即删除。

采集器会等待账号页真实出现 `/video/` 节点，跳过置顶作品后读取最新可见作品，再打开详情页读取五项互动数据。页面返回空列表会显示为失败，不会写入伪造数据。抖音页面结构变化后，可能需要更新采集适配器。
