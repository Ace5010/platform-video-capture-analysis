# 抖音对标监控

本机运行的抖音对标账号监控工作台。数据仅保存在当前电脑，不保存完整视频，也不采集评论正文。

## 第一版包含

- 对标账号主页链接管理（数量不设产品上限）
- 通过当前 Chrome 登录状态访问公开账号主页
- 每 6 小时排队检查，以及手动立即检查
- 视频标题、正文、原视频链接和播放/点赞/评论数字
- 每次采集的数据快照
- 本地口播稿队列入口

## 本地启动

```powershell
npm install
npm run dev
```

打开终端显示的本地地址。首次使用 Chrome 采集组件时，在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”，然后选择本项目的 `chrome-extension` 文件夹。

当前采集器优先读取抖音页面内的结构化数据，并在结构化数据不可用时回退到页面上可见的视频链接。抖音页面结构变化后，可能需要更新采集适配器。
