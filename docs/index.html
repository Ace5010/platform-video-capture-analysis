P 平台视频抓取与分析 查看源代码

LOCAL-FIRST CONTENT INTELLIGENCE

把公开的视频数据，整理成可持续分析的本地资料库

一个面向抖音对标账号研究的 Windows 本机工作台。由 Chrome 扩展负责采集， SQLite 保存长期数据，本地语音识别生成口播稿，用户主动选择后再调用 Qwen 分析完整原视频。

本机运行方式 了解工作流程

本页面是项目说明站。抓取、数据库、Chrome 登录状态和 AI 分析均在用户自己的 Windows 主机上运行，GitHub Pages 不承载业务数据。

CURRENT STATUS

当前实现范围

抖音链路已经实现，其他平台只保留入口，没有把未完成能力包装成可用功能。

抖音

账号建档、最新检查、互动快照、口播识别和完整视频 AI 分析。

预留平台

小红书、哔哩哔哩和 YouTube 当前仅保留界面入口。

CAPABILITIES

核心能力

01

公开数据采集

使用主机 Chrome 中已有的抖音登录状态，采集账号主页与公开视频数据。

02

本地长期存储

账号、视频、互动快照、口播稿和分析结果统一保存在本机 SQLite。

03

完整视频分析

校验目标视频 ID，保留完整媒体语义，不偷偷降级为关键帧或只分析文本。

04

本地口播识别

通过 faster-whisper 转写，使用本地标点模型改善可读性，不改写识别文字。

05

任务恢复机制

任务采用队列、租约、心跳与幂等事件，扩展重启或短暂断线后可以继续。

06

局域网工作台

同一可信局域网内的其他设备可以登录工作台并向主机提交任务。

ARCHITECTURE

工作流程

  1. 1
    网页工作台

    提交采集或分析任务，查看账号、视频和趋势。

  2. 2
    Python 主机服务

    负责认证、任务队列、SQLite、媒体处理和 AI 编排。

  3. 3
    Chrome 扩展

    利用主机登录状态采集公开页面，并校验目标媒体。

  4. 4
    本地 ASR 与 Qwen

    本机生成口播稿；只有主动分析时才向百炼发送完整视频和相关文本。

QUICK START

在 Windows 本机运行

需要 Node.js、Python 3、FFmpeg/ffprobe，以及支持 Manifest V3 的 Chrome。

npm install
npm run setup:asr
npm run dev

工作台：http://localhost:3000

PRIVACY BOUNDARY

重要数据不进入公开仓库

  • SQLite、API Key、模型、临时媒体和本机运行目录均由 Git 忽略。
  • Qwen API Key 使用 Windows 当前用户 DPAPI 加密保存。
  • 普通采集不调用云端模型；完整视频分析只在用户主动触发后执行。
  • 自动测试使用假 Key、临时数据库和模拟分析，不调用真实 Qwen。
